KAWEE - OVERALL BUILD

This ZIP combines the requested KaWee gameplay updates and the realistic sci-fi visual direction.

GAMEPLAY
- 1 to 4 players; a single player can start a room.
- Philippine history trivia with a large shuffled question deck.
- Answer choices are randomized, so the correct answer is not always first.
- Buzzer decides who gets the chance to answer.
- Correct answer DOES NOT award a point by itself.
- Correct answer unlocks a jetpack flight attempt.
- Successful landing on the next moving asteroid = +1 point.
- Miss, short flight, or overshoot = 0 points and return to the last safe asteroid.
- First player to 10 points wins and gets +1 Star.
- Winning round resets points/platform for the next round.
- Players can progress on different asteroids and overtake/pass each other.
- No visible flight meter; timing is visual.
- PC keyboard/click and mobile touch controls.

PROGRESSION
- Elite 6 Stars
- Master 8
- Grandmaster 12
- Epic 16
- Legend 20
- Mythic 25
- Mythical Honor 30
- Mythical Glory 40
- Mythical Immortal 50
- Daily quest panel included.
- Seasons: Jan-Mar, Apr-Jun, Jul-Sep, Oct-Dec.

VISUAL DIRECTION
- Dark cinematic deep-space environment.
- Star fields, nebula lighting and distant planet.
- Irregular rocky asteroid landing points with craters and shadows.
- Detailed astronaut CSS models with reflective visors, suit panels, thruster glow and flight animation.
- Responsive PC/mobile layout.

DEPLOYMENT
1. Upload these files to GitHub.
2. Render: Build Command = npm install
3. Start Command = npm start
4. Node server listens on process.env.PORT.

IMPORTANT
This is a web-game foundation, not a AAA 3D engine. The realistic look is achieved with browser CSS/animation so it remains lightweight. You can replace the procedural astronaut/asteroid art with GLB/GLTF models later without changing the core game rules.
